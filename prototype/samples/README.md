# samples — รูปฉลากยาตัวอย่าง (ข้อมูลสมมติ)

ใช้ลองระบบสแกนฉลาก (FR-02) เมื่อไม่มีฉลากจริงในมือ · เลือกผ่านปุ่ม "ถ่ายรูป / เลือกรูปฉลาก" ตามปกติ

| ไฟล์ | ผลที่ควรได้ |
|---|---|
| `label-after-meal.png` | ร่างครบ · หลังอาหาร เช้า-เย็น (✓1, ✓6) |
| `label-bedtime.png` | ก่อนนอน + ข้อควรระวัง (✓9) |
| `label-before-meal.png` | ก่อนอาหาร ไม่ระบุนาที → ต้องกรอกเอง (✗10) |
| `label-as-needed.png` | ยาเมื่อมีอาการ → ไม่รองรับ (✗4) |

- รูปแบบตามฉลากโรงพยาบาลจริง · ชื่อโรงพยาบาล ผู้ป่วย HN แพทย์ และเบอร์โทรเป็นค่าสมมติ — ร่างต้องไม่มีค่าเหล่านี้
- ข้อความที่ OCR อ่านได้จริงจากรูปเหล่านี้อยู่ใน `../tests/fixtures/ocr-samples.js` (ใช้เป็นข้อมูลทดสอบ `labelParser`)
- **ห้ามวางรูปฉลากจริงในโฟลเดอร์นี้** (มีชื่อผู้ป่วย / HN · PDPA)
